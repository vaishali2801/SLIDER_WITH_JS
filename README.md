🔧 Core Functionality

The slider works on the following logic:

Images are stored in an array

An index variable tracks the current image

Clicking Next increases the index

Clicking Previous decreases the index

When the last image is reached, the slider loops back to the first

When the first image is crossed, it jumps to the last image

This ensures smooth and infinite image navigation.

The slider will run with live refresh support.
